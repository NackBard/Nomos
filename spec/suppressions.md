# Подавления

Подавление — решение разработчика не показывать конкретную находку. Общая часть одинакова для всех языков и проверяется случаем `suppressions` в `conformance/`.

## Директивы

Директива записывается в любом комментарии языка:

| Директива | Что подавляет |
|---|---|
| `nomos-disable [ids]` | находки во всём файле |
| `nomos-disable-line [ids]` | находки, начинающиеся на строке комментария |
| `nomos-disable-next-line [ids]` | находки, начинающиеся на строке после конца комментария |

`ids` — id правил через пробел или запятую, без учёта регистра, с точкой для языковых правил (`CS.NAM001`). Без списка подавляются все правила; `*` означает то же. Находка привязывается к строке своего начала.

Список кончается на первом символе, который не может входить в id или разделитель. Пояснение пишется после тире: `nomos-disable-line ALG001 -- input is bounded`. Слова без тире читаются как id несуществующих правил и ни на что не влияют.

## Что происходит с находкой

Подавленная находка не попадает в SARIF и не влияет на балл здоровья (`spec/metrics.md`). Сырые метрики в facts не меняются. Молчаливого исключения нет: если подавлена хотя бы одна находка, в `diagnostics` есть запись уровня `info` с кодом `suppressed` и их числом.

## Языковые дополнения

Анализатор может иметь свои формы подавления, например атрибуты `[NomosSuppress("ID")]` и `[SuppressMessage("Nomos", "ID")]` в C#. Они не заменяют директивы. Подавлений по путям в `nomos.json` нет (D-040).
