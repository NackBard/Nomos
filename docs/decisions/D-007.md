# D-007. Отдельный проект и категория Paradigm

В ТЗ семь проектов анализаторов по категориям, но правила концепции 3 (инкапсуляция, чистота и другие) ни в одну не входят. Добавлен `Nomos.Analyzers.Paradigms` с категорией `Paradigm`. Его namespace — `Nomos.Analyzers.Profiles`, потому что иначе он перекрывает класс `Paradigms`.
