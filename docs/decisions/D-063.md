# D-063. Агенты и MCP-сервер — отдельное расширение Nomos Agents

Просьба пользователя (2026-11-09): MCP и два ИИ-агента отдельным расширением. Первый проверяет код на соответствие парадигмам, практикам и подходам и имеет две настройки — только написанный код или весь код. Второй оценивает скорость функций и предлагает оптимизации: другие алгоритмы, структуры данных и прочее. Ответы пользователя на вопросы перед работой: модель — **оба варианта** (языковая модель VS Code и Anthropic API по ключу); «написанный код» — **изменения относительно git**; скорость — **статически**, без запуска кода; MCP — **инструменты Nomos для любых агентов**.

- **Пакет `agents/`** — расширение VS Code `honestarchitector.nomos-agents` с `extensionDependencies` на ядро; в нём же MCP-сервер (`out/mcp/server.js`, `bin` `nomos-mcp`). Код делится на `src/core` (без `vscode`: снимок анализа, git, выбор функций, контекст, инструкции агентов), `src/mcp` (протокол и инструменты), `src/llm` (две модели) и `src/extension.ts`. Языковой логики нет: `check-boundary` проверяет и `agents/src`, `check-l10n` — его строки и `package.nls`. Агенты не дают оценок и вердиктов (D-021): инструкции требуют наблюдений с местом, причиной, уверенностью и предложением; балл здоровья передаётся модели с пометкой «статистика, а не вердикт».
- **Данные — из ядра.** Ядро не пишет facts на диск, поэтому `NomosApi` получил событие `onDidAnalyze` (единственное изменение `extension/`, вне контрактов). Агенты берут `runs()` ядра; если анализа нет, вызывают `nomos.analyze`. После каждого анализа расширение агентов пишет снимок в `globalStorage/snapshots/<хеш папки>/`: `<язык>.facts.json`, `<язык>.findings.json`, `rules.json` и `practices.json` ядра, `snapshot.json` с корнем. Контракты не меняются.
- **«Написанный код»** (`src/core/git.ts`) — строки, которые отличаются от базы: `git diff --unified=0 <база>` по рабочему дереву (закоммиченное на ветке, проиндексированное и нет) плюс неотслеживаемые файлы целиком. База — настройка `nomosAgents.base`, иначе общий предок с `origin/HEAD`, `origin/main`, `origin/master`, `main` или `master`; на самой основной ветке — `HEAD`, то есть только незакоммиченное. Функция попадает в проверку, если её строки пересекают изменение; конец функции — `endLine`, иначе метрика `lines`. Удаление отмечает строку, где было, — функция вокруг него тоже считается изменённой. В контексте изменённые строки отмечены `*`, остальное тело функции — контекст. Вне git область «изменения» сообщает причину и предлагает «весь код».
- **Две настройки первого агента** — `nomosAgents.review.scope` (`changes` по умолчанию, `all`); в чате — команды `/changes` и `/all`. У агента скорости та же пара, `nomosAgents.performance.scope`, по умолчанию `all`.
- **Агент проверки** получает: языки и размеры, активные парадигмы модулей с признаками (`paradigmEvidence`), пропущенные правила с причинами (правило без парадигмы модели не применяется), каталог практик и тексты правил находок, находки в функциях и код с номерами строк. Весь код — функции с находками первыми, затем по цикломатической сложности.
- **Агент скорости** опирается на оценки, которые facts уже несут (`spec/metrics.md`, «Оценки сложности функции»): `timeDegree`, `timeLogFactor`, `timeExponential`, `spaceDegree`, `allocationDepth`. Весь код — только кандидаты: экспоненциальное время, степень от 2, `n log n` и выше, растущая память, выделения в цикле или находка категории Algorithms; порядок — экспонента, степень, логарифм, память, глубина выделений, сложность, затем id. Модели запрещено выдумывать замеры; она даёт свою оценку и что такое n, главную стоимость, замену алгоритма или структуры со сложностью после неё, когда оптимизация не нужна и как измерить выигрыш.
- **Размер контекста** — `nomosAgents.contextCharacters` (200 000 символов). Функции, которые не поместились, не выбрасываются молча: их число и имена идут модели и человеку. Функция длиннее 400 строк показывается началом с пометкой.
- **Модели** (`nomosAgents.provider`). `vscode-lm` (по умолчанию) — `vscode.lm`: в чате модель, выбранная там, в командах — первая из `nomosAgents.vscodeLm.family`; ключа нет, согласие спрашивает VS Code. `anthropic` — Claude через `@anthropic-ai/sdk` (единственная новая зависимость времени выполнения: официальный SDK, потоковый ответ, типизированные ошибки); ключ — в SecretStorage (команды «задать» и «забыть ключ»), иначе SDK берёт `ANTHROPIC_API_KEY`. Модель по умолчанию `claude-opus-5-5`, `nomosAgents.anthropic.effort` — `high`, адаптивное мышление, `max_tokens` 64 000, потоковая передача. Для моделей, которые это принимают, включён серверный запасной путь при отказе (`fallbacks: "default"`, бета `server-side-fallback-2026-07-01`); отказ и обрыв по длине показываются человеку. SDK загружается только при выборе `anthropic`.
- **Где работают агенты.** Участники чата `@nomos-review` и `@nomos-perf` и команды «Агент: проверка парадигм и практик» и «Агент: скорость функций» — для тех, у кого нет панели чата; ответ команды открывается новым документом Markdown.
- **MCP-сервер** — stdio, построчный JSON-RPC 2.0, версии протокола `2025-06-18`, `2025-03-26`, `2024-11-05`. Написан без MCP SDK: нужны `initialize`, `ping`, `tools/list`, `tools/call`, `prompts/list`, `prompts/get` — около 100 строк против SDK с его зависимостями (сервер HTTP и прочее) в `.vsix`. Инструменты: `nomos_overview`, `nomos_findings`, `nomos_functions`, `nomos_paradigms`, `nomos_changes`, `nomos_hotspots`, `nomos_source` (только внутри корня). Промпты `review` и `performance` (аргументы `scope`, `base`, `question`) дают те же инструкции и контекст, что и агенты в VS Code: любой клиент MCP (Claude Code, агентный режим Copilot, Cursor) запускает тех же агентов своей моделью. Каждый вызов читает снимок заново. Отсутствие анализа, неверный аргумент и ошибка git — результат с `isError`, а не ошибка протокола.
  - В VS Code сервер регистрирует расширение (`registerMcpServerDefinitionProvider`, `contributes.mcpServerDefinitionProviders`) по серверу на папку рабочей области; запускается бинарником хоста расширений с `ELECTRON_RUN_AS_NODE=1`, отдельный Node не нужен. Поэтому `engines.vscode` агентов — `^1.101.0`; у ядра остаётся `^1.90.0`.
  - Без VS Code: `nomos-ci --out .nomos`, затем `node agents/out/mcp/server.js --snapshot .nomos` — сервер читает `<язык>.facts.json` и `<язык>.sarif`, корень — родитель папки снимка или `--root`.
- **Отвергнуто.** Запуск микробенчмарков агентом (выбран статический путь: запуск кода зависит от среды языка и требует подтверждения человека). Цикл инструментов модели внутри агентов VS Code: контекст собирается заранее и детерминированно, один запрос — проще, дешевле и одинаково для обеих моделей; модели, которым нужно больше, ходят через MCP. Открытый файл или выделение вместо git — не видит изменений в других файлах.

Новые зависимости: `@anthropic-ai/sdk` (время выполнения), `@types/vscode` 1.101.0 (сборка, ради API MCP); `typescript`, `@types/node`, `@vscode/vsce` — те же версии, что у ядра.
