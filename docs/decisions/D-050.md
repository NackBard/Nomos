# D-050. Выпуск — последним этапом; настройка без `nomos.json` — в настройках VS Code

Оба решения принял пользователь.

**Порядок.** Выпуск в Marketplace переносится в конец: расширение публикуется сразу со всеми языками, практиками, русским языком и диаграммой классов. Этапы перенумерованы по порядку работ, в D-049 номера прежние:

| Было (D-049) | Стало | Что |
|---|---|---|
| 10 | 9 | Профиль практик |
| 11 | 10 | Русский язык |
| 12 | 11 | Диаграмма классов UML |
| 13–18 | 12–17 | TypeScript и JavaScript, Python, Java, Kotlin, Ruby, C++ |
| 9 | 18 | Выпуск расширения |

**Открытый вопрос 11.** В папке без `nomos.json` Nomos настраивается настройками VS Code рабочей области: на этапе 9 это `nomos.practices`, позже слои, пороги и парадигмы. Расширение собирает из них файл рабочей области (`contracts/nomos.schema.json`) с командами встроенных анализаторов, кладёт его в своё хранилище и передаёт через `--config`. Контракт `nomos` остаётся минорным, анализаторы ничего нового не читают. Цена: `ci` этих настроек не видит, для запуска без IDE по-прежнему нужен `nomos.json`. Отвергнутый вариант — `nomos.json` без `command` — дал бы одну настройку на оба клиента, но требовал мажорной версии контракта `nomos`.

Пункт «Настройка без исходников Nomos» перенесён из этапа выпуска в этап 9.
