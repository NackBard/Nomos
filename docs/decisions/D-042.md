# D-042. Граф открывается рядом с кодом, как отдельная поверхность

Значок в боковой панели — свой (`media/icon.svg`, временный). Открытие представления Nomos показывает граф на отдельной вкладке рядом с кодом, не забирая фокус, и запускает анализ, если результатов ещё нет. Дерево находок остаётся в боковой панели. Команда `nomos.openGraphWindow` (кнопка на вкладке графа) переносит его в отдельное окно VS Code штатной `workbench.action.moveEditorToNewWindow`.

Отдельное окно не стало поведением по умолчанию: оно открывалось бы поверх основного при каждом клике по значку.

Граф теперь обновляется после каждого анализа: раньше данные приходили только при открытии и переключении уровня. Скрытая страница получает их при показе, потому что без размеров вписать граф нельзя.
