# D-005. Обязательное объяснение на уровне API

`AnalysisContext.Report` бросает исключение при пустом объяснении, а `Confidence` — обязательный параметр. Требование «эвристика не выдаётся за вердикт» обеспечено типами, а не договорённостью. Точная метрика (число строк) может иметь High, но текст говорит, что порог — соглашение.
