# D-022. Протокол: SARIF пишется в файл, facts идёт в stdout

Команда `analyze` печатает facts в stdout; при `--sarif <файл>` дополнительно записывает SARIF в указанный файл и сообщает путь в `checks.sarifFile`. Отдельной третьей команды нет. Причина: SARIF — потенциально большой документ, а клиенту (расширению, CI, GitHub Code Scanning) удобнее иметь файл; facts остаётся единым ответом процесса. Балл здоровья вычисляет анализатор, потому что у него есть и метрики, и находки; расширение его не считает.
