# D-054. Вид находок в редакторе

Пользователь: находки делали весь код жёлтым и мешали работать. Предупреждение VS Code читается как «здесь ошибка», а находка Nomos — эвристика (D-021), поэтому по умолчанию она не должна выглядеть как предупреждение компилятора.

- **Настройка `nomos.diagnostics`**: `hint` (по умолчанию, неяркие точки под кодом, в панель «Проблемы» не попадают), `information` (синее подчёркивание, в «Проблемах»), `level` (прежнее поведение: уровень SARIF — жёлтые предупреждения, красные ошибки), `off` (только дерево «Находки»). Дерево находок от настройки не зависит.
- Смена настройки только перерисовывает diagnostics из последнего анализа, без нового запуска анализаторов.
- Контракты не меняются: `level` в SARIF остаётся как есть, это лишь отображение в одном клиенте. `ci` настройку не видит.

Проверено: тесты расширения (36), `check-boundary`, `check-l10n`, e2e с `nomos.json` (по умолчанию все находки — `Hint`, при `off` их нет, после сброса возвращаются; настройка пишется в изолированный профиль, а не в `.vscode` репозитория). Глазами в VS Code не проверено.
