# D-044. Граф раскладывается по колонкам глубины

Силовая раскладка заменена слоистой: колонка узла — его глубина из D-041, слева то, от чего зависят, справа зависящие. Порядок внутри колонки подбирается по среднему положению соседей, это убирает большую часть пересечений. Расположение теперь повторяемо и само показывает направление зависимости, поэтому стрелки не нужны. Рёбра стали кривыми, чтобы длинные связи не шли сквозь колонки по прямой.

Несвязанные части графа, например C# и Go, идут друг под другом, узлы без рёбер — сеткой внизу. Колонка выше экрана складывается вбок с сохранением порядка: иначе на самоанализе колонка глубины 0 не влезла бы. Короткий граф растягивается по высоте страницы, не больше чем втрое.

Узлы меньше. Экранный размер при отдалении сохраняется лишь до половины строки раскладки, поэтому узлы не могут наехать друг на друга при любом масштабе. Проверено счётом пересечений и скриншотом страницы с реальными facts в тёмной теме: 0 наложений на 17 модулях и 267 типах.
