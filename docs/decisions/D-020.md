# D-020. Языко-родные анализаторы вместо единого .NET-ядра

**Решено.** Каждый язык анализируется самостоятельной программой, написанной на этом языке или с его родными инструментами (C# — Roslyn, Python — `ast`, TypeScript — компилятор TS). Единого ядра с общим IR, разбирающего все языки, не будет. Общим остаются контракты (`contracts/`), спецификации (`spec/`) и тесты соответствия (`conformance/`). Расширение VS Code (`extension/`) — только потребитель контрактов.

**Почему.**

- Точность. Родной инструмент знает язык лучше любого общего IR: разрешение имён, типы, условная компиляция, версии языка. Общий IR вынуждает терять различия или раздувать модель (см. D-003: символы без разрешения, `OpaqueExpression`).
- Поддержка. Новая конструкция языка требует обновить только анализатор этого языка, а не общий слой и всех его потребителей.
- Независимость. Анализатор другого языка пишется людьми, знающими этот язык, без знакомства с .NET.
- Граница ответственности. Расширение не содержит логики языка, поэтому не становится вторым ядром.

**Цена.** Формулы метрик и правила дублируются в каждом анализаторе; расхождения незаметно накапливаются. Компенсация:

- формулы описаны один раз в `spec/metrics.md`, правила — в `spec/rules/*.yaml`;
- `conformance/` содержит эталонные фикстуры на каждом языке с ожидаемыми facts; пройти его обязательно, эталоны считаются вручную, а не берутся из вывода анализатора;
- `parity` в `case.json` требует равенства метрик у эквивалентных сущностей разных языков;
- контракты версионируются, изменения только явным повышением `schemaVersion`.

Остаточный риск: метрики, зависящие от токенизации (Halstead, MI), различаются между языками; для них задан широкий допуск, и они трактуются как порядок величины.

**Следствия для существующего кода.** Проекты `src/` и `tests/` не удаляются. `Languages.CSharp`, `Analyzers.*`, `Core`, `Graph`, `Reporting` и `Cli` переезжают в `analyzers/csharp` на этапе 2 (раздел «Миграция» в `ARCHITECTURE.md` и `ROADMAP.md`). D-017 (Tree-sitter без привязки) отменяется: проект `Languages.TreeSitter` удаляется на этапе 2, поскольку мультиязычного разбора больше нет. D-002 (строки вместо enum) сохраняется как принцип контрактов. D-005 (обязательное объяснение), D-014 (детерминизм) и D-015 (английский текст находок) переносятся в контракты: SARIF-профиль требует `confidence` и `explanation`.
