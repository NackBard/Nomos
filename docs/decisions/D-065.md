# D-065. Баллы и панели масштабируемости — отдельное расширение Nomos Score

Просьба пользователя (2026-11-10): отдельный пакет nomos-score — вкладка Nomos с числовыми показателями устойчивости, расширяемости и соответствия паттернам и методологиям; панели вроде диаграммы рассеяния компонентов и зон Мартина; баллы и статистика по модулям для внешней, быстрой оценки системы и её уязвимых мест, перколяция и другие способы оценить масштабируемость, ключевые проблемы, которые стоит править. Окно открывается двойным щелчком по модулю или компоненту на графе либо для всей системы с боковой панели, как граф зависимостей.

- **Пакет `score/`** — расширение VS Code `honestarchitector.nomos-score` с `extensionDependencies` на ядро, по образцу `agents/` (D-063). `src/core` без `vscode` (граф единиц, баллы, панели, недобор), `src/ui/page.ts` — разметка страницы без `vscode`, рисует `media/score.js` (SVG без библиотек), `src/extension.ts` — команды и панель. Языковой логики нет: `check-boundary` проверяет и `score/src`, `score/media`; `check-l10n` — его строки и `package.nls`.
- **Баллы и D-021.** D-021 убрал оценки из платформы; балл здоровья остался числом с объяснением. Nomos Score продолжает эту линию и не меняет её: баллы — числа 0–100 с выводом из составляющих, формулы — `spec/score.md`, без букв, порога «пройдено», кодов возврата и вердиктов. Анализаторы, ядро, `ci` и контракты баллов не знают; кто не ставит пакет, их не видит. Пороги в `spec/score.md` (`h` в `soft`, 0,5 у зон, 0,25 у узлов распространения) — чувствительность, как в `spec/rules`.
- **Что считается.** По модулю: устойчивость (главная последовательность, циклы, blast radius), расширяемость (CBO, LCOM4, WMC, DIT), соответствие практикам (находки Design, Paradigm, Principles, Security), сопровождаемость (индекс сопровождаемости, цикломатическая сложность, находки Maintainability и Algorithms) и итог. По системе — те же баллы, взвешенные по строкам, и масштабируемость: стоимость распространения изменения (MacCormack), доля наибольшего цикла, разложимость по устойчивости к выбыванию узлов (R, Schneider): для кода граф, который держится вместе, сколько узлов ни убери, — сплошное сцепление, поэтому высокий R снижает балл. Ключевые проблемы — точная раскладка недобора итога по модулям и составляющим, плюс узлы распространения.
- **Панели.** Итоговые плитки; диаграмма Мартина `A × I` с главной последовательностью и зонами боли и бесполезности; рассеяние модулей `Ca × Ce`; рассеяние единиц по входящей и исходящей видимости с классами ядро, общая, управляющая, периферия; кривые перколяции (по степени и по blast radius) с критической долей; распределение blast radius; таблица модулей с сортировкой; ключевые проблемы и узлы распространения. Окно модуля — его баллы с составляющими, место на диаграмме Мартина, единицы с метриками, его проблемы и связи. Несколько языков — переключатель анализа.
- **Как открывается.** Кнопка на заголовке боковой панели Nomos (`view/title` у `nomos.findings`, вклад пакета в чужой вид) и команды «Баллы системы» и «Баллы в отдельном окне»; двойной щелчок по модулю или единице на графе — окно модуля, щелчок по модулю в таблице или на диаграмме — тоже. Без пакета двойной щелчок ничего не делает.
- **Изменение ядра.** Граф узнаёт о двойном щелчке не от Nomos Score, а от любого установленного расширения, объявившего в `package.json` `nomos.inspect.command` (тот же ключ `nomos`, что у языковых пакетов, D-062). Если такое есть, одиночный щелчок по узлу выполняется после паузы двойного щелчка (250 мс), двойной — вызывает команду с `{ language, root, role, id }`; подсказка графа говорит об этом. Команда активирует пакет сама, отдельного API не нужно. Контракты не меняются.
- **Отвергнуто.** Баллы в facts или в `ci` — противоречит D-021 и навязывает числа всем. Библиотека графиков в webview (Chart.js, D3) — новая зависимость ради нескольких SVG-диаграмм, которые в духе `graph.js` рисуются руками. Случайный порядок выбывания в перколяции — недетерминированно; порядок по степени и по blast radius даёт худший случай и воспроизводим. Регистрация обработчика через `NomosApi` — пакет должен быть активен до щелчка, а у VS Code нет события «активировалось другое расширение».

Новых зависимостей времени выполнения нет; для сборки — `typescript`, `@types/node`, `@types/vscode`, `@vscode/vsce` тех же версий, что у ядра.

Изменено 2026-11-13 по просьбе пользователя: панель «Диаграмма Мартина» называется «Абстрактность и нестабильность (главная последовательность)» — по тому, что на ней, а не по автору; подсказка говорит, где зоны боли и бесполезности, и называет автора (Р. Мартин). Метрики в spec по-прежнему «метрики Мартина».
