# D-030. Частичный результат, чистые функции, применимость правил по модулям

**Частичный результат.** Файл с синтаксическими ошибками помечается `parsed: false`, в `diagnostics` появляется запись `warning` с `file` и кодом `syntax-error`, анализатор завершается с кодом 4, остальные файлы разобраны как обычно. Находки на код возврата не влияют. Токены, которые парсер не смог разместить (после ошибки), считаются кодом на своей строке: иначе `loc` сломанного файла был бы 0, а по spec строка с токеном не комментарием входит в `loc`. Код возврата не вынесен в `case.json` (это изменило бы контракт): harness выводит его из эталона — `parsed: false` значит 4.

**Чистая функция** (`fp.pure-functions`) определена в `spec/paradigms.md` консервативно и реализована в `ParadigmSigns` (Abstractions): запись только в свои локальные переменные и параметры по значению; чтение только констант, членов только для чтения и состояния аргументов; вызовы только `System.Math`, `System.String` и чистых функций проекта (наибольшая неподвижная точка); создание только строк и типов проекта без явных конструкторов; никаких `await`, делегатов и неразобранного синтаксиса. Признак занижен намеренно: код с LINQ или внешними библиотеками чистым не считается. Определён и `fp.immutable-types`. Классификация покрыта тестом на 18 функциях, признак — эталоном `paradigm-evidence`.

**Применимость по модулям.** Сбор признаков вынесен из `Nomos.Facts` в `ParadigmSigns`, и движок использует его: правило с парадигмами `oop`, `functional`, `structural` видит только модули, где парадигма проявилась (`spec/paradigms.md`). Facts записывают `skippedRules` по тем же правилам, поэтому запись и поведение движка совпадают. Правило с парадигмой вне этих трёх (набор открыт, признаков для неё в spec нет) не фильтруется по модулям. Последствия: пять фикстур анализаторов (FUN001, FUN002, STR002, STR003, OOP002) получили минимальный признак своей парадигмы — пустые классы и код без ветвлений правила не активировали; в golden-отчёте старого CLI пропала метрика `loc`, которую эмитит структурное правило STR003, у двух модулей без структурных признаков (в facts `loc` модуля есть всегда); находки не изменились.

**Новые случаи conformance:** `oop-cohesion` (DIT, CBO, LCOM4, WMC, ATFD, TCC — подтвердил реализацию `atfd` и `tcc`), `partial-failure`, а в `paradigm-evidence` добавлен модуль с чистой и эффектной функцией.

**Производительность.** Анализ самого Nomos (49 файлов, 233 типа, 1539 зависимостей) занимает около 10 с вместе с запуском; blast radius не является узким местом на таком размере и не оптимизирован. На существенно больших проектах это не проверено.

**Охват `measured`.** Из примерно тридцати правил с числовыми порогами поле заполняется у одиннадцати (D-029). На самоанализе Nomos поле есть у 82 из 272 результатов. Остальные правила (ALG, PRN, STR, PAT и др.) дорабатываются по одному.
