# D-068. Публичные документы — по-английски, с русской копией рядом

Просьба пользователя (2026-11-14), после первой публикации в Marketplace: корневой README был русским, а сообщество, которое найдёт репозиторий по странице Marketplace, читает по-английски.

Решение: документы, которые читают люди снаружи, — английские под прежним именем, русская копия лежит рядом с суффиксом `.ru.md`, вверху каждой — ссылка на другую:

| Английский | Русский |
|---|---|
| `README.md` | `README.ru.md` |
| `docs/ARCHITECTURE.md` | `docs/ARCHITECTURE.ru.md` |
| `docs/EXTENDING.md` | `docs/EXTENDING.ru.md` |
| `docs/ANALYZERS.md` | `docs/ANALYZERS.ru.md` |
| `conformance/README.md` | `conformance/README.ru.md` |

`docs/TRANSLATING.md` уже английский (D-067), README расширений — английские страницы Marketplace. Каталог правил генерирует `npm run rules-doc` в обоих языках: английский — из `title` и `description` правил, русский — из `l10n.ru`, как раньше; `npm run validate` проверяет оба файла. Остальные три пары пишутся руками, и правка одной — правка обеих в том же изменении.

Остаются русскими: `spec/`, решения, `DECISIONS.md`, `ROADMAP.md`, `roadmap-done.md`, `CLAUDE.md` — рабочие документы автора. Английский README говорит об этом прямо.

Почему не один английский файл: автор работает по-русски, и рабочее описание архитектуры ему нужно на родном языке. Почему не перевод всего: spec и решения — сотни страниц живого текста, двойной их вариант разошёлся бы быстрее, чем был бы прочитан.

Там же (2026-11-14): таблица структуры репозитория в архитектуре заменена диаграммой Mermaid (GitHub её рисует) и таблицей анализаторов; скриншоты графа и диаграммы классов пересняты на `score/` без компактного режима (`docs/images/README.md`).
