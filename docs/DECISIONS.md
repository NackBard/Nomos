# Журнал решений

Каждое решение — файл `docs/decisions/D-0xx.md`: что решено и почему. Здесь — список решений, открытые вопросы и ранний список отложенного (D-056). Новое решение — новый файл со следующим номером и строка в конце списка. Старые решения не переписываются: решение, которое меняет прежнее, — новая запись со ссылкой на него.

## Отложено

- Инкрементальный анализ, кэш и сервер LSP для IDE.
- Файл baseline на основе `Finding.Fingerprint`.
- Разрешение NuGet-зависимостей и компиляция по проектам (D-003).
- Taint-анализ и CFG для Security; сейчас там только эвристики по форме кода.
- Межпроцедурные побочные эффекты: FUN001 видит эффекты только в самом методе.
- Адаптеры Python, TypeScript, Java, Go и привязка tree-sitter.
- Локализация сообщений.
- Валидация `nomos.json`: неизвестные Id анализаторов сейчас игнорируются молча.
