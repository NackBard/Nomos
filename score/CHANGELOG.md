# Changelog

## 0.1.0

First release.

- Scores from 0 to 100, each with what it is made of: stability, extensibility, conformance to the chosen practices, maintainability, scalability.
- **System dashboard**: key problems, Martin's diagram, coupling between modules, core and periphery, percolation, change reach, spreading nodes, a table of modules. It opens from the Nomos side bar and can move to a separate window.
- **Module dashboard**: opens with a double-click on a module or type on the Nomos graph, from the system dashboard, or by command.
- Requires the Nomos extension; the double-click on the graph needs Nomos 0.1.1 or newer.
