# Безопасность

[English version](SECURITY.md)

## Как сообщить об уязвимости

Пожалуйста, не открывайте публичный issue. Сообщите закрыто через
[private vulnerability reporting на GitHub](https://github.com/NackBard/Nomos/security/advisories/new):
что затронуто, как воспроизвести и в какой версии. Ответ — в течение недели; исправление выходит новой версией
затронутых пакетов в Visual Studio Marketplace.

Поддерживаемые версии: последняя опубликованная версия каждого пакета. Старые версии исправлений не получают.

## Что запускает Nomos

Nomos читает код и запускает программы, поэтому полезно знать какие:

- **Ядро** запускает анализаторы. Без `nomos.json` они берутся из установленных языковых пакетов; с ним `command`, `cwd`
  и `env` каждого анализатора из `nomos.json` запускаются как написано. Среды выполнения (Python, Java, Ruby, .NET)
  находятся через другие расширения, настройки, переменные окружения и `PATH`.
- **Nomos Agents** запускают `git` в папке (с выключенным монитором файловой системы) и отправляют анализ и код выбранных
  функций языковой модели, которую вы настроили: одной из моделей VS Code или Anthropic API с вашим ключом, который
  хранится в секретном хранилище VS Code. MCP-сервер только читает снимок анализа и файлы внутри анализируемого корня.
- **Nomos Score** ничего не запускает; он показывает анализ ядра.
- **`nomos-ci`** запускает анализаторы из `nomos.json` в вашем конвейере.

Ни одно расширение не работает в недоверенной папке ([Workspace Trust](https://code.visualstudio.com/docs/editor/workspace-trust)):
VS Code держит их выключенными, пока вы не доверите папку. Доверяйте папке, только если доверяете её `nomos.json` и
её настройкам рабочей области. Сами анализаторы разбирают исходный текст и не запускают анализируемый код.
