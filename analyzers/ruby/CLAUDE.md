# Анализатор Ruby

`ruby --disable-gems main.rb manifest | analyze --root …`; через `node run.mjs` (ищет `$NOMOS_RUBY`, затем `ruby` из `PATH`). Локально Ruby 3.3 — `C:\Ruby33-x64\bin` (в `PATH` сессий его может не быть: `export PATH="/c/Ruby33-x64/bin:$PATH"`), в CI — тоже 3.3, минимальная. Тесты: `node run.mjs --test` (свой каркас в `test/tests.rb`, гемов нет). Решения — D-061.

Только стандартная библиотека: Prism (`parse` и `lex`), `json`, `digest`; код проекта не загружается. В Ruby 3.3 Prism 0.19, в 3.4+ — 1.x с другими именами полей: читать их только через `Compat` в `lib/nomos_ruby/support.rb`. Тексты находок — `tx("шаблон spec", …)` в методах с именем правила (`def cc001`), их проверяет тест. `rules.json` и `practices.json` — из `npm run spec-json`.

Модуль — пространство имён; миксин (`module` с экземплярными методами) — тип `trait`, не модуль, чтобы id не совпадали. Методы — `Тип#имя` и `Тип.имя`, функции модуля — `Ns.имя`. Типы значений — `X.new`, литералы, YARD; `semantic: false`. `SourceFile` — ключ хешей по идентичности (хеш `Struct` по значению обходит весь файл). Поиск клонов кэширует периодические отрезки — результат должен совпадать с прямым перебором (тест).
